# autosnap logs

## autosnap logs

Show autosnap daemon logs

```
autosnap logs [flags]
```

### Options

```
  -f, --follow     Follow log output
  -h, --help       help for logs
  -n, --tail int   Number of log lines to show from the end (default all) (default -1)
```
